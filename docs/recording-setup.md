# 录屏工具与设置（Windows）

> 目标：5–10 分钟、1080p、旁白清楚、能随时切"浏览器 → 终端"。
> 推荐 **OBS Studio**（免费、无水印、可切场景）；嫌麻烦用**Windows 自带**的两个。

## 三个选择

| 方案 | 适合 | 优点 | 缺点 |
|---|---|---|---|
| **OBS Studio**（推荐） | 想一次录好、要切画面 | 免费无水印，多场景一键切换，音轨分离，画质最好 | 第一次要配 5 分钟 |
| **Windows 11 截图工具**（Win+Shift+S → 录像） | 只想录一个窗口 | 零安装，点两下就录 | 不能切窗口、不能多场景 |
| **Xbox Game Bar**（Win+G） | 临时录一下 | 零安装 | 只录单个窗口，录不到"窗口切换"的完整过程 |

> PowerPoint 的"插入 → 屏幕录制"也能用，但导出慢、麦克风音量不好调，不推荐。

## OBS 一次性配置（5 分钟）

1. **安装**：obsproject.com → 下载 Windows 版 → 一路默认。
2. **首次向导**：选"仅优化录制，不直播" → 基础分辨率 **1920×1080** → FPS **30**。
3. **加两个场景**（左下"场景"面板 `+`）：
   - 场景 A「浏览器」：来源 `+` → **窗口采集** → 选 Chrome/Edge 窗口；
   - 场景 B「终端」：来源 `+` → **窗口采集** → 选 Windows Terminal / PowerShell。
4. **麦克风**：混音器里 `麦克风/辅助音频` → 选你的耳麦；电平峰值落在 **-12 到 -6 dB**（黄区），不要打到红。
5. **输出**（设置 → 输出）：
   - 录制格式 **MP4**（或 MKV，断电更安全，事后"文件 → 重新封装录像"转 MP4）；
   - 编码器 **x264** 或 **硬件 NVENC**；码率 **6000–8000 Kbps**；
   - 音轨 **1 条 48 kHz**。
6. **热键**（设置 → 热键）：
   - 开始/停止录制：`Ctrl+Shift+R`
   - 切到场景 A / B：`Ctrl+1` / `Ctrl+2`
7. **试录 20 秒**，回放听一遍音量，再正式开录。

## 录制前 3 分钟检查

```
[ ] 关掉微信 / QQ / 邮件客户端（或开"专注助手"屏蔽通知）
[ ] 浏览器缩放 110–125%，关掉其它标签页
[ ] 终端字号 16–18pt、清屏
[ ] 提词器窗口贴着摄像头，字号 34–40px
[ ] 麦克风离嘴 15–20cm，别对着风扇/机箱
[ ] 音量测试：录 10 秒回放，人声清楚、不爆音
[ ] 磁盘空间 > 5 GB
```

## 录制中的节奏

1. 先停 2 秒再开口（方便剪辑去掉开头）；
2. 每段之间停 1 秒，方便切场景；
3. 出错不要停——**停顿 1 秒，重说这一句**，后期剪掉；
4. 全程不要动提词器以外的窗口（会打断画面稳定性）。

## 录完

1. OBS → 文件 → **显示录像**，确认文件大小正常；
2. 用任意播放器看一遍，重点听：开头、每段切换处、结尾；
3. 上传前压一下（可选）：`ffmpeg -i in.mp4 -c:v libx264 -crf 23 -preset veryfast out.mp4`。

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 录出来没有声音 | 麦克风选错 / 被静音 | OBS 混音器看电平条是否在动 |
| 画面卡顿 | 编码器 CPU 不够 | 换 NVENC，或把 FPS 降到 30、码率降到 5000 |
| 文件打不开 | 录制中断 | 用 MKV 格式，事后"重新封装录像" |
| 浏览器窗口采集黑屏 | 硬件加速 | OBS 窗口采集属性里选"Windows 10 (1903 及以上)"模式 |

## OBS 首次配置（照着点，5 分钟）

OBS 装好后第一次打开会有向导，直接**取消**向导，按下面六步点更快。

### 1. 视频（设置 → 视频）

| 项 | 值 |
|---|---|
| 基础（画布）分辨率 | **1920×1080** |
| 输出（缩放）分辨率 | **1920×1080** |
| 常用 FPS | **30** |

### 2. 输出（设置 → 输出）

| 项 | 值 |
|---|---|
| 输出模式 | **简单** |
| 录像格式 | **mkv**（断电可救，事后可重新封装成 mp4） |
| 编码器 | **x264**（CPU 吃力就换 NVENC / QSV） |
| 录像质量 | **高质量** 或码率 6000–8000 Kbps |
| 录像路径 | 默认 `视频` 文件夹，记一下位置 |

### 3. 音频（设置 → 音频）

| 项 | 值 |
|---|---|
| 麦克风/辅助音频 | 选你的耳麦（**别选"默认"**，容易选错设备） |
| 采样率 | **48 kHz** |

### 4. 来源：一个「显示器采集」就够

主界面左下「来源」→ `+` → **显示器采集**（Display Capture）→ 确定 → 选中你的屏幕。

> 为什么不用窗口采集：你的演示从头到尾都在浏览器里，**录整屏**最省事——切标签页、开新窗口都不用动 OBS。
> 代价是桌面上别的东西也会被录进去，所以录制前把桌面清空。

### 5. 快捷键（设置 → 快捷键）

| 动作 | 建议键 |
|---|---|
| 开始录制 | **Ctrl+Shift+R** |
| 停止录制 | **Ctrl+Shift+R** |

### 6. 试录 20 秒

点「开始录制」→ 说两句 → 停止 → 点「文件 → 显示录像」打开看：

- [ ] 画面清楚、菜单能看清
- [ ] 有声音、不爆音、不卡
- [ ] 没有录到微信/QQ 弹窗

### 常见问题

| 现象 | 处理 |
|---|---|
| 画面全黑 | 显示器采集属性里把「捕获方式」改成 **Windows 10 (1903 及以上)** |
| 没声音 | 混音器里看「麦克风」电平条是否在动；右键 → 属性 → 选对设备 |
| 录到 60fps 但卡 | FPS 改 30，编码器换 **NVENC** |
| 文件放哪了 | 设置 → 输出 → 录像路径 |
