# 录完之后：剪辑拼接（剪映 / ffmpeg）

> 你现在有 4–5 个片段（OBS 存在 `视频` 文件夹，文件名是录制时间）。
> 目标：按顺序拼成一个 5–10 分钟的视频，挂上中英字幕，导出 1080p。

## 路线 A：剪映专业版（推荐，免费）

### 1. 安装

- 打开 **capcut.cn**（国内版，不用梯子，免费无水印）→ 下载「剪映专业版」→ 安装。

### 2. 新建与导入

1. 打开剪映 → **开始创作** → 进入草稿；
2. 左上「**媒体** → 导入」→ 全选你的 `.mp4`（Ctrl+A）；
3. 导入后**按录制时间排序**（默认已是），把第 1 段拖到时间轴最左，依次拖入第 2、3…段。

> 拖拽时注意让每段**首尾相接**，中间别留空隙（留了会黑屏）。

### 3. 掐头去尾

每段开头一般有 1–2 秒你点「开始录制」的动作，结尾有停手的画面：

1. 把播放头放到要切的位置；
2. 按 **Ctrl+B**（分割），选中多余片段按 **Delete**；
3. 每段只保留「开口前 0.5 秒」到「说完后 1 秒」。

**切点选在一句话结束之后**，不要切在半句——这是拼接自然的关键。

### 4. 挂字幕

1. 顶部「**文本** → **智能字幕** → **导入字幕**」→ 选 `docs/subtitles/demo.en.srt`；
2. 字幕会自动铺到时间轴上——**但它按原时间轴排的，需要整体对齐**：
   - 先把它拖到你实际开口的时间点；
   - 每段起点的字幕往前/后挪，直到对上；
3. 如果偏差太大，删掉重新导入，或者干脆用剪映的「识别字幕」自动生成（英文识别质量一般，但能省事）。

> 交付要求只强制 README 和旁白是英文；字幕可选。时间不够就**先不挂字幕**，保证内容完整更重要。

### 5. 统一音量

各段录音电平可能不同（尤其你在不同时间录的）：

1. 全选音频 → 右键 → **音量** → 统一调到 -6 dB 左右；
2. 或逐段点开「音频 → 音量」，把峰值拉齐到同一高度；
3. 切点处如果有「咔」声，加一个 0.1 秒的**淡入淡出**。

### 6. 导出

1. 右上「**导出**」；
2. 参数：**分辨率 1080p**、**帧率 30**、**码率 推荐/高**、格式 **MP4**；
3. 导出后**完整看一遍**：开头、每个切点、结尾。

## 路线 B：ffmpeg（会命令行的话，10 秒拼完）

需要先装 ffmpeg（winget 或官网 zip）。装好后：

```powershell
# 1. 把片段按顺序写进列表（注意用正斜杠或双反斜杠）
@"
file 'D:/Videos/2026-11-16 19-16-21.mp4'
file 'D:/Videos/2026-11-16 19-17-21.mp4'
file 'D:/Videos/2026-11-16 19-19-20.mp4'
file 'D:/Videos/2026-11-16 19-20-03.mp4'
"@ | Set-Content -Encoding utf8 D:\pythoncode\concat.txt

# 2. 无损拼接（要求所有片段编码参数一致，OBS 同一设置录的通常满足）
ffmpeg -f concat -safe 0 -i D:\pythoncode\concat.txt -c copy D:\pythoncode\demo.mp4

# 3. 想顺便把字幕烧进去（硬字幕）
ffmpeg -i demo.mp4 -vf "subtitles=docs/subtitles/demo.en.srt" -c:a copy demo_subbed.mp4
```

> `-c copy` 是直接复制流、不重编码，几秒完成；如果报错，去掉 `-c copy` 让它重编码。

## 检查清单（导出后逐项过）

```
[ ] 总时长 5–10 分钟（目标 ~8:30）
[ ] 五个段落顺序正确：架构 → 演示 → 问题 → 成本追踪 → 收尾
[ ] 每个切点没有半句话、没有黑屏
[ ] 音量前后一致，没有突然变大变小
[ ] 画面里没有微信/QQ 弹窗、没有提词器窗口
[ ] 声音清楚，没有爆音
[ ] 文件能正常播放（发给别人试一次）
```

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 拼接处画面跳一下 | 两段窗口位置/缩放不同 | 只能重录那一段，或加 0.2 秒转场遮掉 |
| 声音忽大忽小 | 麦克风距离变了 | 剪映里逐段统一音量 |
| 导出后很糊 | 码率太低 | 导出选「高」或自定义 8–10 Mbps |
| 文件太大发不出去 | 码率过高 | 1080p 8 Mbps 约 60 MB/分钟，8 分钟约 500 MB，正常 |
| 字幕对不上 | SRT 时间轴是模板 | 删掉重挂，或用「识别字幕」 |
