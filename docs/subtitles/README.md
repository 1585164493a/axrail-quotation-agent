## 用法

1. **当提词器**：照 SRT 念，留白处停手看屏幕；
2. **先录后对齐**：录完按段落整体平移（每段第一条见上表）。

## 重新生成

```bash
python tools/make_subtitles.py
```

- 文案在 `CUES`：`(朗读秒数, 英文, 中文, 后面留白秒数)`；
- 段首锚点对齐 1:30 / 5:00 / 7:00，改文案后重跑即可；
- 行宽自动 ≤46 字符，中文按 24 字换行。
