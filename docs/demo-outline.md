# 录屏提纲（不逐字念）

> 每个要点说 1–2 句，看着关键词讲。比逐字稿自然，也不怕忘词。
> 括号里是提示，不用念。

## 0:00 架构（约 60 秒）

- 一句话：多格式询价 → 报价交付，一条链路
- 四种输入 + 扫描件，统一成一套结构
- 定价是代码；模型只读文字
- AgentCore 三件套；题目留白写成假设

## 0:40 必答题 1（约 30 秒）

- 用三样：Runtime 托管 / Gateway 工具+鉴权 / Memory 状态
- 不用四样：Identity（单调用方）、Code Interpreter（价格必须纯函数）、Browser、深度可观测
- 一句收：托管、暴露、状态用；计算、浏览、额外身份不用

## 1:10 必答题 2（约 30 秒）

- 生产栈：LangGraph，6 子 agent、读写分离、写操作挂人工、23 工具
- 留：流程可见、工具是函数、有人点头
- 换：托管、自建 MCP、Mongo 状态
- 点睛：这里不用框架，链路是直的

## 1:40 演示 ①：选邮件、勾文件、报价（约 40 秒）

- 前端在 tools/ui.py
- 按公司和发件人选邮件
- 勾选要读的文件，先只勾正文
- Generate quotation → 右边结果

## 2:20 演示 ②：how / why（约 50 秒）

- 提取出的行 + 建议价
- how：计算逻辑 + 每个值的来源
- why：置信度；分数是规则，解释那句是模型

## 3:10 演示 ③：折扣（约 50 秒）

- 拖动 → 毛利率和报价实时变
- 邮件里的期望折扣 → Needs sign-off，只作参考
- 拖动同时重新生成 PDF 和回信
- 超政策 → 不能直接批，跳审批

## 4:00 演示 ④：held / conflicts / 审批 / 三份产物（约 50 秒）

- 五行里有的报不出 → held 栏逐行解释
- Conflicts 栏：多源不一致
- Approval 提交 → Approvals 页面
- Generate at this discount → review list + 回信 + PDF

## 4:50 演示 ⑤：附件与其它页面（约 20 秒）

- 底部附件可预览、可下原件
- 右上角：邮件清单、价格单、审批

## 5:10 问题三段（约 100 秒）

- **决定的**：数量取最权威文件（图纸>表格>正文）；折扣按档位；算不出就挂起；越线自动审批
- **问人的**：垫片数量待定→问客户；阀体钛合金无价+公差超能力→采购工程；CVR-310 图纸 800/表格 1000→人确认；15% 折扣→经理
- **假设的**：30 天有效；25% 是毛利率（售价=成本÷0.75）；档位按行；5 万签字线；8% 上限；缺失值挂起

## 6:50 成本（约 40 秒）

- `/cost` 实时读 CloudWatch
- 一份约一分钱
- 最大项是 Memory，不是模型
- 对照：估价员 20 分钟

## 7:30 追踪（约 40 秒）

- 左：本次会话每次报价（RFQ、总额、调用数、耗时）
- 右：工具级 —— 哪个工具、多少毫秒、输入输出
- 下：规则链，每条带规则号和金额

## 8:10 改进 + 收尾（约 30 秒）

- 三个改进：图表语义、审批通知、可信度权重
- 收尾：规则管文件里有的，人管没有的，中间写成假设
